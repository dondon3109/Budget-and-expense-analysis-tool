Zoption 2.1.1 is an Android-only hotfix that restores the system status bar in the installed app. The hosted web application is unchanged, so users already on 2.1.0 receive this fix only by installing the new signed APK.

## Status bar fix

### Symptom

The installed Android app opened in immersive fullscreen: the status bar with the time, Wi-Fi, and battery indicators was hidden.

### Cause

The Trusted Web Activity was generated with Bubblewrap display mode `fullscreen`, which writes `DISPLAY_MODE = "immersive"` into the Android manifest. Android Browser Helper 2.6.2 maps that value to `ImmersiveMode`, and Chrome hides the system status bar for the whole app.

### Resolution

The wrapper now uses display mode `standalone` (`DISPLAY_MODE = "standalone"`), which Android Browser Helper maps to the default mode: the app keeps its standalone, chrome-free window while the system status bar remains visible. This changes only the Android wrapper; the web manifest was already `"display": "standalone"` and the app layout already accommodates `env(safe-area-inset-top)`.
